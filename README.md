# Iclirius Distribution

Public distribution-only repository for audited Iclirius release artifacts.
The Iclirius source repository remains private.

Each release asset is built from a tagged source commit, scanned for secrets
and private machine state, and published with a SHA-256 checksum.

`64abcd44d90c7dd956ed237955947956eade4cc6`.
